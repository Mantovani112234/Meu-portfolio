## Sobre o projeto

Este é meu portfólio pessoal, criado para apresentar meu perfil, meus conhecimentos e meus projetos na área de Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- HTML
- CSS
- Bootstrap
- JavaScript

## Funcionamento

O site possui um menu para acessar as partes de Perfil, Projetos e Contato. Também apresenta meu e-mail e meu GitHub.

## Recurso novo

Adicionei um efeito nos cards dos projetos. Quando passo o mouse sobre eles, mudam de cor e aumentam um pouco de tamanho.

## Como foi feito

Utilizei CSS com as propriedades `:hover`, `transition` e `transform` para criar esse efeito.
